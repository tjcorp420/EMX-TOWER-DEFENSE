EMX TOWER DEFENSE V4 BTD UPGRADE - LIGHT ZIP

This ZIP intentionally contains code files only. It does not include your existing assets/ folder or sfx/ folder.

Install:
1. Keep your current project assets/ and sfx/ folders exactly where they are.
2. Replace your root files with these files:
   - index.html
   - style.css
   - script.js
   - manifest.webmanifest
3. Deploy/test from the project root.

Added in this upgrade:
- BTD-style layered glitches:
  Purple Multi-Layer -> Green Layer -> Blue Layer
- Special enemies:
  Shielded, Fast/slow-immune, Camouflaged
- Tower targeting modes:
  First, Last, Strongest, Closest
- New support/economy towers:
  EMX Hub and Crypto Miner
- Better tower panel:
  Targeting toggle, utility tower stats, branch info
- Ability cooldown progress rings
- More pop feedback:
  +coin text, layer-pop text, shield/fast/camo indicators
- Extra performance protection:
  projectile cap direct-hit fallback, layer child cap, less heavy wave spam

Notes:
- Camo enemies require Shadow Sniper, Anti-Air Prism Path B, or EMX Hub scanner support.
- Fast enemies resist slow effects.
- Shielded enemies heavily reduce weak hits; high damage, pierce, laser, and splash are stronger answers.
