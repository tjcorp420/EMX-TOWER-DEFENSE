EMX CORE DEFENSE V7 BATTLES LIGHT

This is a code-only upgrade. It intentionally does NOT include existing EMX asset images or SFX.
Keep your current assets/ and sfx/ folders in the project.

Replace these root files in Spck/Vercel:
- index.html
- style.css
- script.js
- manifest.webmanifest

New in V7:
- EMX Battles Bot mode from the main menu
- Eco income system: earn coins every 6 seconds based on current eco
- Send Glitches tab with BTD Battles-style enemy sends
- Each send shows cost, cooldown, and eco impact
- Cheap sends increase eco
- Strong all-in sends can reduce eco but pressure the bot harder
- Opponent bot state: bot core lives, eco, coins, tower count, pressure, and defense scaling
- Opponent bot sends enemies at your map while you defend
- Tower Overdrive global battle boost, limited to 3 uses
- Glitch Surge global battle boost, limited to 3 uses
- Battle HUD showing eco tick, opponent core health, and pressure
- Mobile-friendly cooldown overlays on send buttons
- Existing V6 systems remain: 15/20 wave pacing, shards, win screen, upgrades, pierce, AoE, statuses, bosses, campaign, endless, and daily challenge

Testing notes:
1. Open the app.
2. Tap EMX Battles Bot.
3. Use the Send tab to build eco with Blue/Green sends.
4. Place towers and press Start Round.
5. Try Tower Overdrive when your side gets crowded.
6. Try Glitch Surge before expensive camo/shield/tank sends.
