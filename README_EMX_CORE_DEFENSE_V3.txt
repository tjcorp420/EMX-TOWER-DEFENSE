EMX Core Defense V3 - Full Tower Defense Upgrade

Drop this whole folder into Spck/Vercel exactly as-is.
Open index.html or deploy the folder root.

Major upgrades in V3:
- Full campaign map select system
- 6 landscaped levels with different paths, colors, modifiers, and unlock requirements
- Endless Mode and Daily Challenge buttons
- Permanent Core Shards upgrade lab
- Star rating system after each level
- Achievements that reward shards
- Enemy health bars and damage numbers
- Boss health bar and boss warnings
- New enemy types: runners, shield cores, swarm bugs, flyers, tanks, healers, EMP wardens, splitters, bosses, final boss
- Tower branching at level 3 with two upgrade paths per tower
- Anti-Air Prism tower for flying enemies
- Field tools: Barrier, Boost Pad, Scrap, Mine
- Commander abilities: EMP Freeze, Repair, Overdrive, Mine, Drone Swarm
- Bonus cache drops during waves
- Combo rewards
- Sound settings, vibration toggle, reduced FX toggle
- Mobile layout built so the top HUD does not cover the playfield

Sound folder support:
- assets/sfx/name.wav
- sfx/name.wav
The game tries assets/sfx first, then sfx. It also has fallback generated sounds if browser playback blocks a file.

For iPhone:
- Tap Play/Start once to unlock browser audio.
- Make sure Silent Mode is off if you want louder playback.
